# QQ 邮箱

## 一、授权

1. 登录 [QQ 邮箱](https://mail.qq.com/)，在设置的账户/账号安全/第三方服务中找到 IMAP/SMTP，完成安全验证并生成本项目专用授权码。菜单名称随邮箱版本变化，以页面为准。
2. 双击本目录 `connect.bat`，隐藏输入授权码，再输入完整邮箱地址。使用授权码，不使用 QQ 登录密码。适配器使用 TLS：IMAP `imap.qq.com:993`，SMTP `smtp.qq.com:465`。
3. 脚本通过列文件夹验证账户后保存凭据；`check.bat` 使用已有授权码，不重新授权。然后启动实际应用 Gateway，再配置 Agent 路由。
4. 现有工具支持文件夹、邮件搜索/正文、草稿、已读状态和移动；发信工具只给绑定账户自己发，没有其他收件人/抄送/密送参数。读取不修改已读，定位校验文件夹、UID 和 UIDVALIDITY。

本机凭据：`%LOCALAPPDATA%/mcp-cross-app-trace/qq-mail.credential.xml`。邮箱授权可能允许比当前工具更广的 IMAP/SMTP 操作；实际读取对象与写入范围仍须取得用户同意。

## 二、取消授权

### 1. 停用本平台入口

暂停本应用的 Agent 任务。双击上一级 `manage-apps.bat`，选择本应用后选“停用”（菜单 5）；也可在项目根目录运行：

```sh
node tools/application-catalog.js disable qq-mail
```

模块停用在重新加载 Gateway 后生效。清理凭据前先停止仍在使用它的本项目 Gateway/上游：前台控制台按 Ctrl+C，受管后台实例用 `npm run unmount`。仅关闭网页或关闭强制监控开关不等于取消授权。

### 2. 在服务端撤销权限

1. 登录 [QQ 邮箱](https://mail.qq.com/)，返回生成授权码的账户安全/第三方服务设置，打开授权码或设备管理。
2. 找到本项目专用授权码，使用页面提供的删除/撤销操作。若没有单个授权码撤销入口，在确认其他客户端影响后关闭本账号 IMAP/SMTP 服务；这会影响使用相同服务的其他邮件客户端。
3. 不要把修改 QQ 密码、退出网页版或删除本机文件当成已撤销授权码。若页面无法管理，使用 [QQ 邮箱官方帮助](https://service.mail.qq.com/) 查询“授权码/管理服务”，按当前账号页面操作。
4. 撤销授权码不会删除邮件；取消授权不需要清空收件箱、草稿或废纸篓。

### 3. 删除本机保存的凭据

打开 `%LOCALAPPDATA%/mcp-cross-app-trace`，删除 `qq-mail.credential.xml` 及仅属于本项目的副本。不要删除其他邮件客户端的账户数据。

### 4. 清理客户端并确认结果

在 Codex/DSH 中停用本应用的受管 MCP 条目，或按 [路由教程](../agent-routing/README.md) 重新准备、检查和应用不包含本应用的计划，然后重载客户端。只处理本应用，保留其他应用和开发工具；所有保留连接仍须 `required=false` / `failOnStartupError=false`。

退出仍持有旧凭据的 Agent/上游进程；如果曾在终端、系统环境变量或其他 MCP 客户端保存相同凭据，也清除本应用对应的副本。只删本机文件不会使云端 Token 自动失效，云端撤销也不会删除已经采集的历史原文。历史数据按 [停用指南](../../docs/user/DISCONNECT.md) 单独处理。

完成后在应用中心确认本应用已停用，客户端不再调用它，并检查平台后台的撤销/停用结果。工具列表仍可见不代表业务授权仍有效；不要为验证撤销结果再次运行 `connect.bat`、重新登录或创建业务对象。以后需要恢复时，重新授予权限并绑定。
