强制 Gateway 监控

开启：应用调用经过 Gateway，网关或目标应用不可用就停止监控任务。关闭：允许路由器在网关不可用时回退到应用上游，回退调用不会被本平台采集。普通聊天始终可以启动。

保存后用于后续调用；不会重启网关、修改 Agent 启动配置或重新授权。直接使用其他 API、浏览器或脚本的行为不在此开关控制范围内。
