# 任务与数据流

首页提供四项展示能力：当前任务概览、按应用汇总的流向、字段关联解释、失败与后续成功步骤定位。读取完整任务快照后一次渲染；概览始终使用当前任务全量记录，时间线及字段筛选仍分别作用于自己的区域。

概览按已知工具分类汇总读取、写入和其他操作次数，包含失败及读回核对。未知工具不根据名称猜测动作。成功表示已记录的调用返回成功，不代表用户目标已完成。缺少请求或返回记录会另行提示。

应用卡片显示“GitHub → 飞书文档”等流向，飞书文档与多维表格按实际工具区分。每个卡片分别显示写入字段数和候选关联数；同一字段的多个来源不重复计为多个写入字段。点击展开原文、关联依据和候选证据。相同应用内部的读取与写入也会展示。完整字段图保留为可展开视图。

判断说明覆盖原文一致、格式转换后匹配、多个可能来源、来源尚不确定、未找到来源。说明依据该写入字段的全部候选，筛选不会将多个候选改称唯一来源。没有候选不代表数据一定来自任务之外；匹配不证明 Agent 的实际使用意图。保留原规则、置信程度、事件与字段路径供核对。

异常概览保留全部失败记录，并可定位到时间线或后续成功步骤。同任务、同网关、同应用和同工具下，失败结束之后开始的成功调用才可关联。保留的完整请求参数按对象键排序后比较：参数相同显示“相同参数的后续调用成功”；参数不同、缺失或截断仅显示“同类操作后续成功，不能确定是本次重试”。并发且先于失败结束的成功不会被当作后续恢复。此处描述记录事实，不判断 Agent 的重试意图。

长文本在卡片、表格、说明、原值对话框中换行；表格宽度固定在容器内，手机端允许表格内部横向滑动。长原文提供展开全文，实际记录不截短。字段图按实际文本宽度省略，并用节点边界裁剪与悬停全文防止越界；两个方向的标题不再根据应用排序猜测。

## 任务命名、搜索和分组

展开「当前任务概览 → 任务命名与分组」，填写名称并保存。任务选择器与列表使用该名称；列表「搜索任务」支持名称、编号、应用和 Agent，条件随链接保存。

记录有明确任务编号时按编号分组；`X-Trace-Task` 产生的任务后缀也作为明确编号。只有通用运行编号的操作按 **30 分钟空闲间隔**提供建议，标注「推断建议」，不把它当成已经确认的用户意图。

选择分组后，时间线、概览和字段流向一起缩小到该组。点击「采用建议分组」保存建议；输入前段调用数可拆分当前组；选择另一组可合并。新增调用不偷偷塞进已经手工整理的组，进入「新增 / 未分组操作」。合并、拆分目前针对同一个原始运行内的调用。

名称及手动分组保存在 **本浏览器的本地存储**，按事件库区分。清除浏览器数据或换浏览器不会携带这些整理结果。原始数据库及原运行编号不修改。切回「完整运行」可查看跨分组关联；分组内存在分组外候选时仍标不确定，不把多候选变成唯一来源。

## 大任务和长正文

任务列表每页 100 条，时间线与写入字段每页 200 条，可前后翻页。统计及筛选按全部记录计算。图最多一次绘制 200 条关联并提示总数；应用分组、字段表与证据仍可继续查看，筛选能缩小绘图范围。

工作台使用紧凑快照：长值展示前 320 字符并标明预览。关联判定、字符位置及证据编号始终来自完整原文；「查看这条关联的证据」和请求/结果查看入口可读全文。未变化的时间线与流向复用有界缓存；新记录及数据库文件变化使缓存失效。

## 网页应用中心

左侧「应用中心」集中展示十二款应用：本机绑定账户/应用、启用状态、实际网关连接、工具发现、最近历史故障、定义变化及字段提取情况。展开「查看账户绑定与停用教程」直接阅读对应应用说明。

首次展示保存的工具定义，**不冒充本次在线发现**。「检查连接和工具」只经 Gateway 进行握手与完整工具发现，支持分页，不读取业务正文、不刷新授权、不写入外部应用。未绑定时按教程使用已有 `connect.bat`；网页不会自动启动授权或改客户端配置。

工具定义与已经保存的路由缓存比较，分别列出新增、删除与参数/输出/注解变化。出现变化后应复核适配、更新工具缓存和重载客户端；检查本身不自动覆盖基线。无基线、历史缓存、工具发现失败与本次可用分开表示。

读写分类沿用数据流分析器的同一套策略；名称推断明确标注，未知工具显示「待分类」。字段数/路径来自历史实际提取，未调用或未提取的工具标待实测；这不是全工具覆盖率，也不表示字段关联算法正确率。


## 刷新与显示

页面时间按本机时区显示为 `YYYY-MM-DD HH:mm:ss`。没有新数据时自动刷新保留页面、展开状态和滚动位置；手动刷新会重新读取快照，读取失败保留上次完整视图。

应用中心的强制监控按钮见 [开关说明](MONITORING_SWITCH.md)；不再使用某个账户时按 [停用指南](DISCONNECT.md) 操作。
