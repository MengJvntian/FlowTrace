# 使用教程

从 [安装与启动](INSTALL.md) 开始，先运行无需账户的虚构演示。页面包含任务、调用时间线、字段流向和应用中心。

实时监控使用start-monitor.bat / npm run serve。按 [应用目录](../../applications/README.md) 绑定自己的账户，再准备实际清单并安装Agent路由。默认Mock清单不能代替真实应用授权。

用 [任务工作台](task-workbench.md) 学习查看证据；用 [开关说明](MONITORING_SWITCH.md) 了解故障恢复；不再使用时按 [停用指南](DISCONNECT.md) 清理账户与路由配置。
