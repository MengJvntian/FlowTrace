# 停用与取消授权

仓库不会自动撤销你已授权的账户。准备停止使用时，按下面顺序操作，保留其他应用与插件的配置。

十二款应用的具体权限及撤销方法见 [应用授权与取消授权目录](../../applications/README.md)。每份 README 都分为“授权”和“取消授权”；应区分模块停用、云端撤销与本机文件删除。

1. 在独立工作台应用中心关闭强制监控；需要时保留普通聊天。
2. 从 Codex/DSH 配置停用本项目管理的应用路由，重新加载客户端。任何保留的应用都必须可选：required=false / failOnStartupError=false。
3. 执行 npm run unmount 停止本项目受管服务。独立页面控制台用 Ctrl+C 关闭。
4. 在各供应商的账户授权/应用后台撤销本项目集成、Token 或 OAuth。自建应用无需时按平台要求停用。不要删除其他业务应用。
5. 清理本机保存的对应凭据：Windows通常在 %LOCALAPPDATA%/mcp-cross-app-trace；Google授权在用户目录 .google_workspace_mcp 的各 credentials-* 文件夹。删除前确认仅属于本项目，必要时先备份。
6. demo-data 中的数据库与导出含原始业务信息，停止服务后自行备份或删除；不要上传。

只关网页不会撤销云端授权；只关闭强制监控也不会停用路由或删除令牌。各应用 README 提供具体绑定和检查步骤。

Google 共用 OAuth 客户端时，撤销一项关联可能影响其他 Google 应用；只停用单个模块不能宣称云端授权已经撤销。腾讯文档的公开说明未明确独立 Token 撤销入口；没有确认旧 Token 失效前，记录为“本机已停用，云端撤销待确认”。飞书的 `logout -a <App ID>` 仅清理指定应用本机令牌，不代替服务端撤销。
